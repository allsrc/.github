# Allsrc community health files

This is the special [`.github`](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)
repository for the [Allsrc](https://allsrc.dev) organization.

- `profile/README.md` is the text shown on the organization's profile page.
- The community health files here are the defaults for every Allsrc repository that does not define its own: `CODE_OF_CONDUCT.md`,
  `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md`, `PULL_REQUEST_TEMPLATE.md` and the `ISSUE_TEMPLATE/` forms.

A project that needs something specific (for example Agent Taskbay's spec-driven contribution rules) keeps its own file in its own
repository, which takes precedence over these defaults.
