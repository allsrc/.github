# Allsrc

**Open-source tools for AI agents, interoperability, protocols and developer infrastructure.**

Allsrc is the engineering home for projects created and maintained by [Shashi Kanth G S](https://shashikanth.me). The work centers on
making AI agents interoperable, observable and governable: protocol tooling for [A2A](https://a2a-protocol.org), agent runtimes and
harness patterns, and the developer infrastructure around them.

## Projects

| Project | What it is |
| --- | --- |
| [Agent Taskbay](https://github.com/allsrc/agent-taskbay) | The human operations console for A2A agent workflows: start work, track it, approve it, audit it |
| [SpanPlane](https://github.com/allsrc/spanplane) | Open-source agent observability and runtime visualization |
| [a2a-wrapper](https://github.com/allsrc/a2a-wrapper) | Turn AI backends (Copilot SDK, OpenCode, Claude, Codex and more) into spec-compliant A2A servers from a JSON config |
| [a2a-schema-contract](https://github.com/allsrc/a2a-schema-contract) | Community specification and conformance suite for schema-constrained A2A payloads, with a [TypeScript SDK](https://github.com/allsrc/a2a-schema-contract-sdk) and [reference implementations](https://github.com/allsrc/a2a-schema-contract-reference) |
| [a2a-mcp-skillmap](https://github.com/allsrc/a2a-mcp-skillmap) | Expose any A2A agent as an MCP tool server |
| [agent-harness-patterns](https://github.com/allsrc/agent-harness-patterns) | Runnable engineering patterns for governed, production AI agents, with a [cookbook](https://github.com/allsrc/agent-harness-cookbook) |
| [mcp-ssh-bridge](https://github.com/allsrc/mcp-ssh-bridge) | A FastMCP bridge that lets AI assistants run commands on remote servers securely |
| [ScenePipe](https://github.com/allsrc/ScenePipe) | AI-authored, Remotion-rendered, brand-consistent short-form video |

Agent protocol extensions published by Allsrc are specified at [extensions.allsrc.dev](https://extensions.allsrc.dev).
